# ml-lightbox-pro — releases

Repositório público somente com os pacotes oficiais (ZIP) do plugin **ml-lightbox-pro**, da ML Lopes Design.

O plugin instalado no WordPress consulta este repositório para oferecer atualizações automáticas. O código-fonte fica em um repositório privado.

Cada versão publica um único arquivo: `ml-lightbox-pro-vX.Y.Z.zip`.
